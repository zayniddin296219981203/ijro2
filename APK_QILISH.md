# APK Yaratish Ko'rsatmasi

## 1. Node.js o'rnating
https://nodejs.org → LTS versiyani yuklab o'rnating

## 2. EAS CLI o'rnating (CMD da)
```
npm install -g eas-cli
```

## 3. Expo akkaunt yarating
https://expo.dev → Sign Up (bepul)

## 4. Login qiling
```
eas login
```

## 5. Bu papkaga kiring
```
cd ijro-monitor
npm install
```

## 6. APK build qiling
```
eas build --platform android --profile preview
```

## 7. Natija
- 10-15 daqiqada tayyor
- https://expo.dev/accounts/[sizning_nomingiz]/projects/ijromonitoring/builds
- APK ni yuklab oling

## Eslatma
- Build bepul (oyiga 30 ta)
- Internet kerak
- Expo akkaunt kerak
